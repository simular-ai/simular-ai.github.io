# Simular Research

The [Simular Research homepage](https://research.simular.ai/) is served from `index.html` through GitHub Pages. The archived Simular API reference is served from `api.md` at `/api/`. Existing root-level API bookmarks redirect to their original headings in the archive.

Run `bundle install` and `bundle exec jekyll serve` with Ruby 3.3 to preview the site and the API archive together.

The homepage hero at `assets/research/misty-valley.jpg` was created with the built-in ImageGen tool. The generation prompt was:

> Generate an original landscape photograph as a 2:1 hero backdrop for a quiet academic research website. Look over a broad valley of layered evergreen ridges and a narrow winding river after a light rain. Soft illuminated fog blows through the middle distance, with the most detailed dark fir silhouettes on the far right edge. Keep the left half light, low contrast and uncluttered for a dark title set in HTML. Elegant natural photography, overcast morning, warm silver mist, subdued deep green and gray. No people, buildings, roads, text, logos, frames, or watermarks.
